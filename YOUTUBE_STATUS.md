## HOW TO DRIVE THAT DIALOG WITHOUT LOSING WORK (learned the hard way today)

1. Open the draft, then click **Show advanced settings FIRST** — before typing anything. Clicking
   it *after* typing wiped the title and description three times.
2. Set AI use, Made-for-Kids and tags while the form is empty.
3. Type the title and description LAST, then go straight to Next.
4. Never press **Escape** in the dialog — it closes the whole thing (it does save a draft).
5. After each publish, RELOAD the list page before touching the next row. Element references go
   stale the moment the table re-renders, and a stale click silently does nothing.
