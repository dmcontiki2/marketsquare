## What the code says about "the right person" (read, not walked)

- **Estate agency (owners):** there is no "list on behalf of an owner" record. An agent lists as herself
  (`listings.seller_email` = the agent), and the owner appears only as evidence: the signed mandate credential
  `category.property.mandate` on that listing. A buyer's introduction goes to the agent's Intros and only the agent can
  accept (`create_intro` → `GET /intros` scoped to `seller_email`; `accept_intro` requires the session to be the
  seller). The agency admin sees a count ("Intros to agents") and cannot accept. **So "the right person" is the agent
  who holds the owner's mandate — the owner is never in the loop.** If David means the owner should also see or approve
  introductions, that is a design question, not a bug (L30).
- **Placement agency (workers):** `org_enrol.py` cannot create a listing by design. The agency enrols the worker, she
  opens her own key link and publishes her own advert, so `seller_email` is the worker and she receives the introduction
  herself. The placement console is labelled "launching soon".
