## Faults
1. Agency console intro count is always 0: bea_main.py `_agency_agent_rollup` queries `intro_requests WHERE LOWER(seller_email)=?` but intro_requests has no seller_email column, the exception is swallowed (`intros_n = 0`), so "Intros to agents" and each agent's INTROS never move.
2. Console first-load race: ms.js `openAgencyConsole` reads localStorage `ms_aa_email` before `msAdoptSession()` (/quick/me) has stored it, so a signed-in admin arriving without that key sees "No agency is linked to this account yet" until a reload.
3. Invited agent shown by email local-part: `_agency_agent_rollup` names rows from users.name (empty for a new invitee) and ignores agency_members.agent_name entered on the invite form.
4. Invite email / link never mention the Agent Hub, FFC or PPRA: bea_main.py `_mint_agent_invite` links to plain `/?signin=`, and My Space (`goTo('myspace')` for a seller with no listings) has no Agent Hub card — the only door is Sell > Seller Hub > "Agent Hub".
5. Go-live gate contradicts the copy: Agent Hub says the FFC is "required to go live" (AS_VERT.property), but PUT /agents/profile/publish returns 422 until PPRA is also submitted.
6. Credential upload drops the chosen file: ms.js `asCredUpload` clears the file input with a toast when the number box (as-cred-ref-*) is empty, instead of keeping the file and pointing at the box.
7. Trust Score disagrees across screens: Agent Hub shows 50 before and after the FFC was verified, the agency console and listing show 60, buyer listing card showed 50.
8. Mandate is labelled "required per listing" (ms.js EL_CRED_SIGNALS, Edit Listing) but neither the Coach flow nor POST /advert-agent/publish / PUT /listings/{id}/publish asks for or enforces it, so an agent listing goes live with no owner mandate and buyers see no mandate signal.
9. Coach Publish leaves the button on "Publishing…" for the 409 needs-terms case long enough that a user would tap away; the Terms step then opens on the dashboard (ms.js `aaDoPublish` → `dashPublish`), and `PUT /listings/530/publish` 403s once before the Terms screen.
10. Wrong location data: listing_lat/lng are null for a suburb listing, so nearby amenities come from the Pretoria centroid, and the Seller Hub auto-links the Moreleta Park house to the Apartheid Museum, Sterkfontein and Cradle of Humankind as "World Heritage site" (Ditsong is not one) — five cards pushing Edit/Pause off-screen.
11. Agency has no city: `_AgencyCreate` (bea_main.py) carries only countries, so "ZA, Pretoria" cannot be recorded for an agency.
12. Every page load for a non-admin fires a 404 `GET /agencies/by-admin/<email>` (ms.js My Space agency-card probe) — console noise for every user.
13. Agency tier label mismatch: users.seller_tier = 'agency' for Anneliese, but the console shows "Starter · active".
14. Buyer's accepted intro offers "I bought from them" on a house listing and gives no on-screen line naming the agent/agency or "check your email" — a stranger would not know what happens next.
