REPORT

Right edge, halfway down.

A narrow navy tab with REPORT running vertically. It is fixed to the viewport, so it stays exactly there as you scroll — it does not move with the page.

That slot was chosen because it is the only fixed position nothing else on any page already claims: the bottom bar, the toast, the sticky buttons and the offline banner all live along the bottom edge, and the top-right corner belongs to the dev toggle.

If you cannot see it: the server flag Tester fault reporting on the +1 page is still off, or the page needs a hard refresh (Ctrl + F5). It also only renders for a gated tester or a superuser — an ordinary visitor never sees it.
