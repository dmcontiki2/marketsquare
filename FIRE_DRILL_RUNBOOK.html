🔥 Fire Drill Runbook — FLIP-DRILL-1

One rehearsed hour that converts "validated READY" into "we have done it". Drill A flips live traffic onto the open-weight standby and back. Drill B (after A passes) simulates a full Anthropic ban.

An unrehearsed failover is a hope, not a capability. The flip-back is rehearsed too — aborting cleanly is a passing result, not a failure.

Choose the hour

A quiet weekday mid-morning (SAST) with you at the laptop and one hour undisturbed. Traffic is pre-launch light, so any hour works — what matters is that you are watching. Everything below is reversible in one click at any moment.

Drill A — the live flip ≈ 1 hour · dashboard only

1 · Pre-flight (10 minutes)

  • ✓Site green: open trustsquare.co, log in, one search works. /health reports ok (the dashboard shows it).
  • ✓Backups fresh: last night's 03:17 R2 backup ran (checkpoint log) — nothing about this drill touches data, but rules are rules.
  • ✓Dashboard → Infrastructure → AI Providers card: Scaleway shows as keyed STANDBY (its golden-set pass is 18 Jul: 7/7 text, 2/2 vision). If the confirm copy still says "outage use only", that wording is stale — this drill is exactly the evidence that retires it.
  • ✓Note the time. Open a notepad for observations (or tell me in chat as you go — I'll keep the log).

2 · The flip (one click)

On the AI Providers card, set the active provider to scaleway. That writes launch_switches.ai_active via POST /admin/flags; the app picks it up within ~10 seconds (cache window). Anthropic automatically becomes the fallback lane — the safety net inverts, it never disappears.

Every AI feature now runs on mistral-medium-3.5-128b (EU, open weights) — the ONE-MODEL STANDBY you ruled on 18 Jul.

3 · The watch hour — exercise every AI muscle

Spread these over the hour, roughly every 10 minutes. You are looking for: empty or nonsense AI replies, obvious slowness, error toasts.

  • ✓AI search — a natural-language search a buyer would type ("bakkie under R200k near Cape Town"). Interpretation still sensible?
  • ✓Free example button — any category's example (/ai/example route). Output arrives, reads well?
  • ✓Listing quality feedback — open a draft listing, request the quality/SPS feedback. Coherent?
  • ✓Vision draft — draft a listing from a photo. This is the tier that fails first on weaker models; Mistral passed 2/2 on the golden set, now prove it live.
  • ✓Triage / coach touchpoint — any assistant-style flow you normally test.
  • ✓BIT self-test — run trustsquare-bit-agent\bit_cycle.py once mid-hour. All markers should PASS exactly as on Anthropic.

⛔ Abort criteria — flip back immediately if any of these appear

Empty AI replies · a customer-visible error · vision draft produces garbage · BIT reports an S1 failure · anything that makes you uneasy.

The abort IS part of the drill: set active back to anthropic on the same card (≤10 s to take effect), confirm the failing feature recovers, and record what broke. A clean abort still proves the switch works both ways — that is a pass on the mechanism, with homework on the lane.

4 · Flip back & capture the evidence

  • ✓Set active back to anthropic. Confirm one AI feature responds.
  • ✓Evidence: screenshot of the card while scaleway was active · the hour's AI spend rows (the spend log now carries a provider column — they should read scaleway) · BIT result · your notes.
  • ✓Tell me the verdict + notes — I write the CHANGELOG entry (FLIP-DRILL-1), update the vendor-strategy addendum, retire the stale "outage use only" confirm copy, and mark the Durability Map.

Drill B — the ban simulation run only after A passes · 20 min

AI_DRILL_BAN — Claude ceases to exist for 20 minutes

Drill A proves the standby carries traffic by choice. Drill B proves survival when Anthropic is gone: the P2a drill overlay excludes the lane exactly as if banned (T3) — but it is a routing overlay only: no breaker state is written, no LOUD alarm fires, and unsetting it ends the drill instantly. The design doc calls this the first monthly T0 drill.

# start the drill (one line, from your terminal):
ssh root@178.104.73.239 "mkdir -p /etc/systemd/system/marketsquare.service.d && printf '[Service]\nEnvironment=AI_DRILL_BAN=anthropic\n' > /etc/systemd/system/marketsquare.service.d/drill.conf && systemctl daemon-reload && systemctl restart marketsquare"

# ... run the same watch-hour spot checks (15–20 min is enough) ...

# end the drill (removes the overlay completely):
ssh root@178.104.73.239 "rm /etc/systemd/system/marketsquare.service.d/drill.conf && systemctl daemon-reload && systemctl restart marketsquare"

During the drill the dashboard shows a DRILL badge (P2b adds the full breaker lights). PASS = every AI feature served with Claude absent. That sentence, in the CHANGELOG, is the strongest independence statement TrustSquare can make short of owning the box.
