Cloud ↔ laptop: nothing stopped, wiped or overwritten (RUL-193)

Every path to GitHub now takes the other side's work in first, stops cleanly on a real conflict, and runs the same scan.
① Take in first

One shared step before every push: fast-forward or normal merge. Never rebase, reset or force.

Stop, not wipe

A real conflict aborts the push with every file as it was, and SYNC_CONFLICT.txt names the files.

② No overwrite, any lane

The pre-push hook refuses a push that would drop GitHub commits; only MS_ALLOW_OVERWRITE=1 (by design) passes.

③ Same scan both ways

The cloud ship job runs the laptop's strict pre-deploy scan, so neither side ships a red the other trips on.
