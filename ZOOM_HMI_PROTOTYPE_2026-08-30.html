The path is the product

A saved path is a standing interest. “For You” is simply your saved paths, run fresh — visible, editable, no black box.

Five rules

  1. One question at a time. The app asks the facet that splits the remaining set hardest — measured, not hand-ordered.
  2. Every option shows its true count, from the same query as the list. Zero-count options are removed, so a dead end is unreachable.
  3. Geography is one chip that deepens — city › suburb › street — not four separate filters.
  4. Typing is a shortcut through the tree, landing you mid-path with the chips filled in.
  5. The path is saveable. That is what makes “For You” honest.
