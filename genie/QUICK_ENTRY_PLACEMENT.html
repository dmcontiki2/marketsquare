AThe empty hero body Put it here

There is already an empty, styled, positioned container sitting under the logo — <div class="hero-body"></div> at marketsquare.html line 624 — so a full-width Quick Listing bar drops in without moving a single pixel of anything below it.

It is the only slot every visitor passes before they have decided anything, which is exactly the introduction you described.

Wording matters: the harness runs both directions, so the bar should read like "Tell us what you want, or list yours — 5 taps" rather than a sell-only label.

BFull-width tile in the Categories grid Second, not instead

The Local Market tile already proves the pattern (grid-column:1/-1, aspect-ratio:6/1), so this is a five-minute copy — but among six category tiles it reads as a seventh category rather than as the fast way to do anything.

CRe-point the Sell button Required follow-up

openSellNav() currently opens the account-picker sheet into the long flow, so unless it lands in the same harness you will be running two sell doors at two different frictions and the familiar one never wins.

DA floating button or a sixth nav tab No

The bottom bar already owns that zone with five items, and a floating button would cover the Featured and Heritage rows on a phone.

The one thing standing in the way

The slot is free but the destination does not exist yet as an app screen: genie/HARNESS.html is a standalone file, there is no route for it in main.py, and genie/README.md still opens with "DESIGN ONLY. Nothing is wired into the app."

So the work is not the button — it is wiring the harness in as screen-quick first; the bar in slot A is then about twenty lines.
