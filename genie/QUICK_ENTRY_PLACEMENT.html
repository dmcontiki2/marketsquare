Where it went Done

Into <div class="hero-body">, which had been empty since LM-19 removed the stats row — so the door cost no layout argument with the Categories grid, Featured, Heritage or the For You feed.

Violet #7C3AED is the Quick tile's own colour under QUICK-TILE-1 and no category tile uses it, so the door cannot read as a seventh category. It hides in demo mode with the rest of the seller surface.

The half that wasn't done Fixed

quick.html had been deployed since 14 Sep, but every Publish ended in "DRY RUN — no server is wired to this prototype" — a front-page door pointing at that would have been the worst kind of live: visible, tried, and ending in nothing.

The hand-over now fills itself on the app's own origin and posts to the same /listings every other listing goes through — one server, one rulebook.

The long sell path stays Ruled

David, same day: "We still need the long sell path where more options and details can be added?" — so the bottom-nav Sell button is not re-pointed at the harness.

They are not alternatives: Quick composes a thin card and the server stores every one as draft, while photos, the full detail set, the score and publishing belong to the guided flow.

The seam already existed — GET /listings/mine?email= matches on seller_email, which is what the hand-over writes — so the draft is waiting the moment he signs in with the same address. The result box now says that in words and links back (QUICK-HANDBACK-1).

Deferred on purpose One

GET /quick/me off the ts_user cookie (RUL-125(a)) does not exist, so the door reads the app's own signed-in marker on the same origin instead — same answer, no new surface, four lines to swap when the endpoint is built.

One thing for David His call

/quick.html answers anonymously while trustsquare.co itself is still behind the pre-launch gate — so a stranger can now write a real draft through a door he cannot yet walk back through.

Rejected No

A floating button or a sixth nav tab — the bottom bar already carries five items and a floater would cover the Featured and Heritage rows on a phone.
