Bug audit of today's changes

I checked everything shipped today (languages, one-tap publish, the Quick app, the arrival card, the AI spending rules), plus the older code those changes touch. Every confirmed defect is fixed, deployed and checked on the live site. Nothing is left open.

4 critical 5 high 8 medium 17 of 17 fixed and live

Critical: someone could act as another person

AUDIT-Q1One-tap publish could post under someone else's accountnew today

Typing an existing member's email into Quick published an advert in their name without a sign-in. Now a stranger only gets a draft, and the real owner gets an email to publish it. New addresses still publish in one tap. Each connection is limited to 5 a day. Fixed.

AUDIT-AUTH-1Publish, edit and "my adverts" trusted a typed emailolder

These three used whatever email the page sent. They now act only as the signed-in person. On the live site, a request without a sign-in is refused (401). Fixed.

DELETE-BIND-1Anyone could delete any advertolder

I found this while preparing the real publish test. The app key is public (it ships inside ms.js), and it was enough to delete any normal advert. The seller delete also needed only the owner's email. Now only admins can delete by ID, and seller and wonder deletes need the owner's sign-in. Fixed, locked as RG-0445.

AUDIT-XSS-1Advert titles could carry web-page codeolder

A title or description could hold markup that later ran in other people's browsers. Titles and descriptions are now saved as plain text wherever they are written. Fixed, locked as RG-0442.

High: data leaks and lost work

AUDIT-L1The public advert page returned the seller's email

Anyone viewing a single advert could see the seller's email and the translation working notes. Now only the seller sees their email, and the language panel loads from a page only the owner can open. Fixed.

AUDIT-Q2The browser could set its own trust score

Quick accepted trust score, picture paths, specs and status straight from the page. Those fields are now removed before saving. Fixed.

AUDIT-Q3A refused publish lost the way back

When publishing was refused (for example, a full plan), the draft email never went out and the button led nowhere. Now the email is sent and the button opens the draft. Fixed.

AUDIT-L2/L3Edited adverts kept the old translation

After a seller changed their words, the old isiZulu or Afrikaans version still showed. Editing now clears the translation, its check-back and the English search copy, but only after the owner check passes. Fixed.

AUDIT-S4AI-translated text was not escaped

Translated text went into the page unescaped. It is now escaped the same way seller text is. Fixed.

Medium: correctness and cost

AUDIT-L4The photo marker was sent for translation

It is now removed before translating, and links are removed from the English search copy. Fixed.

AUDIT-L5Switching language broke Back and counted a false view

Changing language now redraws the page without logging a view or changing where Back goes. Fixed.

AUDIT-L6The translator accepted any language

It now accepts only the languages actually offered, so AI money can't go on languages we don't offer. Fixed.

AUDIT-L7AI spend was counted before the call worked

Spend is now counted after a successful call. Each advert gets at most 5 AI drafts a day. Fixed.

AUDIT-Q4Quality preview crashed on odd input

The preview now converts field types instead of failing with a server error. Fixed.

AUDIT-S1AI calls could hang a page

AI calls now time out after 18 seconds. Fixed.

AUDIT-S2The "your advert is live" email opened the wrong place

The link now signs the seller in and opens their advert card. Fixed.

LEDGER-CHUNK-1The full regression run could not finish

This was not last week's sandbox problem, where the drive could not be mounted after a Windows update. This time the board had grown to 427 checks, about 10 minutes of work, while each command is capped at about 3 minutes. The new --chunk mode runs in timed steps and resumes where it stopped. The full board ran clean, with 0 regressions. Fixed, locked as RG-0440.
