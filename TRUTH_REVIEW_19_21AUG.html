The prevention — the Evidence Ladder (now standing method in CLAUDE.md)

PROBED
A live measurement made this session. The only grade that may be reported as fact — “live”, “done”, “active”, “green”. Canonical probes: /health · /flags · /auth/providers · /dashboard/bit · /id-verify/status · post_deploy_status.json · regression ledger · rulings_check. One command each.
EXECUTED
The code path actually ran (a test that calls the endpoint, not one that greps for it). Reportable as “passes in test”. Guards that only read source text sit BELOW this rung — that is how F7 shipped.
READ
A file, doc, code pattern, dashboard or cached JSON. May only be voiced as “the file claims…” and MUST be probed before it reaches a report. Probe and file disagree → the probe wins and the file is fixed in the same run. Every doc status line carries its date + how it was verified.
RECALLED
Memory of a past session. Never reportable. Go probe.
ℹ️ Design rule riding along (RG-0133, generalized): no instrument may default to a health colour and no hand-written verdict may wear one — grey/UNVERIFIED until data answers, NOT MEASURED if nothing probes it. An instrument that fails green is worse than no instrument.
